Mô tả: Xây dựng website hỗ trợ dịch phụ đề phim nước ngoài với giao diện thân thiện, sử dụng Firebase làm cơ sở dữ liệu. Công nghệ sử dụng: HTML, CSS, JavaScript, Firebase (Auth, Firestore, Storage), OCR (Tesseract / Google Vision API – dự kiến tích hợp).
